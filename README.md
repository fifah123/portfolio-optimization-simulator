# Portfolio Optimization & Diversification Simulator

> A quantitative investment portfolio simulator that determines optimal asset allocation based on expected return, risk tolerance, and diversification constraints.

---

## 📌 Overview

The **Portfolio Optimization & Diversification Simulator** is a quantitative finance project designed to help investors explore how capital can be allocated across multiple financial assets to achieve a desired investment objective.

The project combines **statistical analysis, portfolio theory, mathematical optimization, Monte Carlo simulation, and backtesting** to evaluate different investment strategies.

Given a set of financial assets and an investor's objectives, the system analyzes historical market data and determines how much capital should be allocated to each asset.

The main objective is to answer:

> **"Given a target return and a defined risk tolerance, how should capital be distributed across multiple assets to achieve the best risk-adjusted portfolio?"**

The project also demonstrates how diversification can reduce portfolio concentration and potentially improve risk-adjusted performance.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze historical price movements of selected financial assets.
2. Estimate expected returns and portfolio risk.
3. Analyze correlations between assets to evaluate diversification benefits.
4. Determine optimal portfolio allocation using mathematical optimization.
5. Compare multiple portfolio construction strategies.
6. Visualize the efficient frontier and optimal portfolios.
7. Simulate potential future portfolio outcomes using Monte Carlo simulation.
8. Evaluate portfolio strategies through historical backtesting.
9. Provide an interactive dashboard for portfolio analysis and optimization.

---

## 💡 Problem Statement

An investor typically faces a trade-off between **return and risk**.

Investing heavily in high-return assets may increase the potential return of a portfolio, but it may also expose the investor to higher volatility and larger losses.

On the other hand, investing equally across many assets may reduce concentration risk but does not necessarily produce the most efficient risk-adjusted portfolio.

Therefore, the key problem is:

> **How can we determine the optimal proportion of capital allocated to each asset while balancing expected return, portfolio risk, and diversification?**

This project addresses the problem using portfolio optimization techniques based on **Modern Portfolio Theory**.
